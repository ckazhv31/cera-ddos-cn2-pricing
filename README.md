## CERA机房到底防什么

洛杉矶Ceranetworks机房的防御机制分三层：硬件级DDoS清洗、100G以内秒解、超过100G在15分钟内解封。

50G防御是所有套餐的标配，这个"50G"指的是每个IP能承受的DDoS攻击峰值。具体来说：
- 50G以内的攻击触发后几秒内自动清洗，业务几乎无感
- 50-100G的攻击在几秒到几十秒内完成清洗并解封
- 超过100G的大流量攻击会先进黑洞，15分钟后解封

这套机制适合大多数中小规模的持续性DDoS攻击，尤其是那种凌晨突然来一波、持续几小时的恶意流量。如果你被盯上需要对抗超过200G的持续攻击，或者业务对"15分钟黑洞"完全零容忍，CERA可能扛不住，需要考虑专业的大带宽高防机房。
